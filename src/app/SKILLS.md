# Agent Skills & Permissions

## Allowed Tools
- **Terminal:** Read/Write access to run `npm` commands and start the dev server.
- **File System:** Permission to create/edit files in the `src/` directory.
- **MCP Servers:** Full access to the `supabase-mcp` server for schema lookups and SQL execution.

## Specialized Capabilities
- **Financial Audit:** Permission to use the internal Python sandbox (Code Execution) for GST math verification.
- **Browser Preview:** Ability to take screenshots of the localhost preview to verify the POS layout.
